# Krokly

Щоденний тренажер англійської для українців: 5 слів і фраз на день з інтервальним повторенням,
Читанка, де українська поступово стає англійською, словник і тест рівня за шістьма навичками.

Це веб-застосунок (PWA): відкривається за посиланням, встановлюється на телефон і працює без інтернету.
Збірка готова, нічого компілювати не треба: достатньо викласти ці файли на GitHub Pages або Netlify.

Прогрес кожної людини зберігається лише на її пристрої.
Шрифти Onest і Unbounded поширюються за ліцензією SIL Open Font License (див. папку fonts).
